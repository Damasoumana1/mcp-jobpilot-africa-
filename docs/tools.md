# MCP Tools

## search_jobs

Search internship and early-career opportunities by keyword, location, remote status and duration.

## get_job

Get the full details of a specific job.

## match_candidate_to_job

Compare a candidate profile with a job and return the score, matches, missing skills and recommendations.

## create_application

Create an application tracking record for a candidate and a job.

## update_application_status

Update the application state and notes.

## generate_interview_questions

Generate interview questions from the candidate profile and the advertised job requirements.

## get_application_checklist

Return a personalized application preparation checklist.
